An anatomical model of the right radius for anatomy education and medical simulation development.

| Setting | Recommendation |
|---|---|
| Printer | FDM 3D printer |
| Material | PLA |
| Nozzle | 0.4 mm |
| Layer Height | 0.20 mm |
| Wall Count | 3 |

| Supports | Evaluate in slicer |

Orient the radius diagonally across the build plate when possible.

Use supports only where necessary to preserve anatomical details.
