## Model
OpenHumerus Intraosseous (IO) Trainer

## File
OpenHumerus_IO_Trainer.stl

## Purpose

A 3D-printable training model designed to support educational medical simulation involving the anatomy of the humerus and intraosseous access training.

## Recommended Starting Settings

| Setting | Recommendation |
|---|---|
| Printer | FDM 3D printer |
| Material | PLA or PETG |
| Nozzle | 0.4 mm |
| Layer Height | 0.20 mm |
| Wall Count | 4 |
| Infill | 20–30% |
| Supports | Recommended |
| Build Plate Adhesion | Brim recommended |
| Print Speed | 50–70 mm/s |

## Orientation

Orient the model to preserve important anatomical features while minimizing unnecessary supports.

Check the slicer preview carefully before printing.

## Estimated Print

Estimated print time: 5–10 hours

Estimated material: 100–200 g

## Assembly

If the model contains multiple components, test-fit all printed parts before final assembly.
