## Model
Human Humerus

## File
humerus.stl

## Purpose
An anatomical model of the human humerus for anatomy education and medical simulation development.

## Recommended Starting Settings

| Setting | Recommendation |
|---|---|
| Printer | FDM 3D printer |
| Material | PLA |
| Nozzle | 0.4 mm |
| Layer Height | 0.20 mm |
| Wall Count | 3 |
| Infill | 10–15% |
| Supports | Recommended |
| Build Plate Adhesion | Brim if needed |
| Print Speed | 50–80 mm/s |

## Orientation

Position the humerus at an angle that provides adequate build plate contact while reducing the amount of support material required.

Check the slicer preview before printing.

## Estimated Print

Estimated print time: 4–8 hours

Estimated material: 75–150 g

## Quality Recommendations

For greater anatomical detail, consider using a 0.12 mm layer height.
