## Model
Human Tibia and Fibula

## File
Human_tibia_and_fibula.stl

## Purpose
An anatomical model of the lower-leg bones for anatomy education and medical simulation development.

## Recommended Starting Settings

| Setting | Recommendation |
|---|---|
| Printer | FDM 3D printer |
| Material | PLA |
| Nozzle | 0.4 mm |
| Layer Height | 0.20 mm |
| Wall Count | 3 |
| Infill | 10–15% |
| Supports | Recommended |
| Build Plate Adhesion | Brim |
| Print Speed | 50–70 mm/s |

## Orientation

Place the model vertically or at a slight angle depending on the size of the model and available build volume.

If the model is too large for the printer, consider reducing the scale or splitting it into sections.

## Estimated Print

Estimated print time: 6–12 hours

Estimated material: 100–250 g

## Quality Recommendations

For anatomical detail, consider using:

- 0.12–0.16 mm layer height
- 3–4 walls
- Reduced print speed
