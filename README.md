# OpenMedSim3D
OpenMedSim3D is an open-source community dedicated to developing,sharing, and improving 3D-printable models for medical simulation.  By connecting educators, clinicians, and makers, the project promotes affordable, accessible, and high-quality simulation tools to support healthcare training worldwide.

In this repository you will find a library of medical simulation STL 3D print files.  Many of these files come from NIH 3D, the National Institutes for Health online library of 3D print files of general medical utility.  There are some medical simulation 3D files on NIH3D, but not a lot, and many are of so so quality and not specifically engineered for medical simulation.  We hope that by providing these files in our repository we will attract a global community to download, use, improve and optimize these files.  Medical education is expensive, and 3D printing offers an opportunity for educators in resource limited areas to 3D print medical simulation anatomic models and consumables for far cheaper than these items cost when purchased and shipped from medical simulation retailers.
